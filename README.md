# 💬 VibeChat

**VibeChat** — это современное веб-приложение-мессенджер, созданное на чистом **JavaScript** с кастомной системой рендеринга, вдохновлённой **React**.  
Проект реализован без фреймворков, но при этом поддерживает динамическое обновление интерфейса, работу с **WebSocket (Socket.IO)** и интуитивный UI.

---

## 🚀 Основные возможности

- 🔐 **Регистрация и авторизация** пользователей
- 💭 **Приватные чаты** между двумя пользователями
- 👥 **Групповые чаты** с возможностью добавления нескольких участников
- ⚡ **Реальное время**: обмен сообщениями через **WebSocket (Socket.IO)**
- ✍️ **Статусы активности**:
  - «печатает…»
  - «онлайн / офлайн»
- 📷 **Отправка изображений** в чат
- 🧩 **Модульная архитектура** — проект легко расширять и поддерживать

## 💡 Как запустить проект локально

> ⚠️ **Важно:** API сервера защищено настройками CORS, поэтому с локального окружения отправка запросов может быть недоступна.  
> Рекомендуется использовать **деплойную версию**, чтобы всё работало корректно.

2. Запусти локальный сервер (например, через VSCode или Node):

# 🧠 Архитектура

VibeChat построен на модульной архитектуре, где каждая часть отвечает за конкретную зону ответственности:

**state.js** — хранит текущее состояние приложения (пользователь, активный чат, список чатов и т.д.)

**handlers.js** — обрабатывает события UI

**handlers-socket.js** — слушает и обрабатывает события от WebSocket сервера

**chat-components.js** — отвечает за рендеринг интерфейса чата

**utils.js** — вспомогательные функции, аналогичные React-хукам или JSX-фабрике

Рендеринг построен на кастомной функции createElement, которая работает по принципу JSX:

```javascript
createElement("div", {
  className: "chat__message",
  children: [createElement("p", { text: "Привет!" })],
});
```
